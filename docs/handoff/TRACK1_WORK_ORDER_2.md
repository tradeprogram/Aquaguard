## 유일한 잔여 항목 — 경사를 어디서 받을 것인가

### 증상

**데모가 아직 트리거되지 않습니다.** 토양 샘플러는 정상 작동하는데
(`부지 토양: 산청 토양격자 5m 자동 샘플링(MEASURED)` 경고 확인), 확률이 임계
0.7에 닿지 않습니다.

### 원인 (트랙③ 실측)

`Module A.run()`은 경사를 **계약 입력 `static.slope_deg`에서** 받습니다
(`envelope.py:59`). 반면 `scripts/45`가 만든 위험영역 레이어는 **실제 5m 경사
래스터로** 계산됐습니다. 둘이 어긋납니다.

AOI 전역을 500m 격자로 994개 점 훑었습니다.

```
전부 정확히 0.687  ·  0.7 이상: 0개
```

좌표를 바꿔도 값이 안 변합니다 — 계약값 32.5°가 고정으로 쓰이기 때문입니다.
`A_soilmap_critical` 레이어 안쪽(레이어 기준으로는 prob ≥ 0.7인 픽셀)에서도
점 평가는 0.687입니다.

경사만 바꿔보면 판정이 갈리는 지점이 분명합니다.

| slope_deg | landslide_prob | |
|---|---|---|
| 30.0° | 0.601 | |
| 32.5° (현재 계약값) | 0.687 | 임계 미달 |
| **33.0°** | **0.701** | **임계 초과** |
| 35.0° | 0.750 | |
| 40.0° | 0.829 | |

**0.5° 차이가 트리거를 가릅니다.**

### 왜 저희가 못 채우는가

- 5m 경사 래스터(`data/dem/산청_slope_5m_5179.tif`)가 저장소에 없습니다
  (README §11의 "재취득" 목록)
- 토양격자 npz의 필드는 `c_kpa`, `phi_deg`, `gamma_kn_m3`, `z_m`, `m0` 뿐이라
  경사가 없습니다

여기서 저희가 경사값을 골라 넣으면 **임계를 넘기려고 숫자를 고르는 것**이 되므로
하지 않았습니다.

## 지시 — 경사 격자를 데이터로 내보내 주십시오

### 왜 `run()`이 직접 샘플링하면 안 되는가

트랙①이 토양 커밋에 직접 쓰신 원칙 그대로입니다.

> dNBR은 일부러 제외 — 산불 등급은 계약(`static.dnbr_class`)이 주는 값이고
> 격자가 덮어쓰면 계약 밖 데이터로 결과가 바뀐다

`slope_deg`도 같습니다. 게다가 스키마상 `static.required`에 들어 있는 **필수 입력**이라
(`contracts/module_a.schema.json`), 격자가 조용히 덮어쓰면 계약이 깨집니다.

**그러니 계약을 지키는 방향은 하나입니다 — 호출자(Module O)가 측정된 경사를 넣는 것.**
계약은 "경사는 호출자가 준다"고 돼 있고, 지금 문제는 그 호출자가 하드코딩 32.5°를
넣고 있다는 것뿐입니다.

### 트랙①이 할 일

토양격자와 **똑같은 방식**으로 경사 격자를 내보내 주십시오. 구조가 이미 있으니
새로 만들 건 없습니다.

- `module_a_landslide/data/sancheong_slope_5m.npz` — 기존 토양격자와 동일한
  `transform`/`crs`/원해상도 5m
  - 또는 기존 npz에 경사를 필드로 추가해도 됩니다(파일이 하나로 줄어 더 낫습니다)
- **양자화는 uint8, 0.25° 간격을 권합니다.** 0~63.75°를 덮고 위 표대로 0.5°가
  판정을 가르므로 그 절반이면 충분합니다. 토양격자와 같은 압축률이면 2MB 안팎이라
  커밋 가능합니다
- 샘플러 함수 하나 — `soil_sampler.sample()`과 같은 시그니처
  ```python
  def slope_at(x_5179: float, y_5179: float) -> float | None:
      """AOI 밖이거나 격자 미탑재면 None."""
  ```
  AOI 밖에서 `None`을 주는 동작도 토양 샘플러와 같게 맞춰 주십시오 — 남의 지역
  지형을 쓰지 않는다는 같은 이유입니다

### 트랙③이 할 일 (알려만 주시면 저희가 합니다)

- Module O의 §10 데이터 접근 계층에서 `slope_at()`을 호출해
  `module_a_input["static"]["slope_deg"]`에 넣습니다 — 건물·농경지·침수심 래스터를
  넘기는 것과 같은 경로입니다
- 데모 fixture(`contracts/module_o.example.json`)의 하드코딩 32.5°를 제거합니다
- 샘플이 없으면(AOI 밖) 기존 계약값을 그대로 쓰고 경고를 남깁니다

**함수 이름과 npz 경로만 알려 주시면 그날 바로 연결합니다.**

### 완료 기준

```bash
AQUAGUARD_MOCK_MODE=0 python -c "
import json
from module_o_orchestrator import run
inp = json.load(open('contracts/module_o.example.json', encoding='utf-8'))['input']
ap = run(inp)['data']['alert_package']
print('prob', ap['landslide']['landslide_prob'])
print('노출건물', len(ap['exposure']['exposed_buildings']))
"
```

`landslide_prob ≥ 0.7`이고 `노출건물`이 0이 아니면 끝입니다. 그 순간
D·E·G·H가 처음으로 전부 돌고, 3D 지도에 실제 위험 지오메트리가 올라갑니다.
